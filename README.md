# 신재하

행사 현장에서 쓰는 웹 서비스와 업무 자동화를 만듭니다. Claude Code 로 만들고, 테스트와 원본 대조로 맞는지 확인합니다.

## 공개 프로젝트

**[roster-agent](https://github.com/Shin-923/roster-agent)** · 명단 검수 에이전트
엑셀 명단을 AI 가 검증 도구로 검사하고, DB 저장은 사람이 승인한 뒤에만 합니다. 승인 뒤에도 서버가 다시 검사하고, 바꾼 내용은 변경 이력으로 남깁니다.
TypeScript · Fastify · React · Claude API · Vitest

## 회사에서 만든 것

회사 업무로 만든 코드라 공개하지 않습니다. 자세한 설명은 이력서와 포트폴리오에 있습니다.

| 프로젝트 | 기술 |
|---|---|
| 통역사 공고 · 섭외 관리 웹 서비스 (정식 오픈 전) | Java · Spring Boot, JavaScript, SSE, AWS EC2 |
| 수출상담회 부스 현황판 · 상담 예약 | JavaScript, Google Apps Script, Google Sheets |
| 통역원 상담 자료 · 만족도 설문 사이트 (행사 3일 운영, 응답 388건) | JavaScript, Google Apps Script |
| 상담 기록 6,600여 건 대조 · 일괄 정정 | Python(openpyxl) |
